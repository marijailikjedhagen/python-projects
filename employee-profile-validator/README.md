# Employee Profile Validator

Checks and cleans up employee data using Python's built-in string methods.

- Finds the `@` in an email and extracts the username (`find`, slicing, `in`)
- Cleans messy names and emails (`strip`, `title`, `lower`, `upper`)
- Turns an email username into a display name (`replace`)
- Removes dashes from a phone number, and splits and rejoins an address (`split`, `join`)
- Checks how codes and emails start and end, and counts characters (`startswith`, `endswith`, `count`)

Run it: `python employee_profile_validator.py`
