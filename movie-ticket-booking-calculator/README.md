# Movie Ticket Booking Calculator

Works out whether a user can book a movie ticket and what it costs, based on:

- **Age:** 18+ can book; 21+ can book evening shows
- **Membership:** members aged 21+ get a discount of 3
- **Weekend or evening shows:** an extra charge of 2
- **Seat type:** service charge of 5 (Premium), 3 (Gold) or 1 (other seats)

Final price = base price + extra charges + service charges − discount

Change the variables at the top of the file to try different bookings.

Run it: `python movie_ticket_booking_calculator.py`
