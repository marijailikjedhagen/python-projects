# Travel Weather Planner

Decides whether a commute is possible:
- up to 1 mile: walk, but only if it isn't raining
- 1–6 miles: bike, if you have one and it isn't raining
- over 6 miles: car or ride-share app

Change the variables at the top of the file to try different situations.

Run it: `python travel_weather_planner.py`
