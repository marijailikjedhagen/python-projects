# Employee Profile Generator

Builds an employee profile from basic details and reads information out of an employee code.

- Joins strings with `+` and `+=`, converting numbers with `str()`
- Formats an employee card with an f-string
- Uses string slicing to pull the department, year and initials out of a code like `DEV-2026-JD-001`

Run it: `python employee_profile_generator.py`
