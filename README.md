# Python Projects

Small Python projects I built while working through the freeCodeCamp Python certification.
Each folder is a standalone script you can run with `python <file>.py`.

| Project | What it does | Concepts practiced |
|---|---|---|
| [RPG Character](rpg-character/) | Creates and validates a role-playing game character sheet | Functions, input validation, `all()`/`any()`, string building |
| [Caesar Cipher](caesar-cipher/) | Encrypts and decrypts text by shifting letters | String slicing, `str.maketrans`, `translate`, default arguments |
| [Apply Discount](apply-discount/) | Calculates a price after a percentage discount | Type checking, conditionals, return values |
| [Travel Weather Planner](travel-weather-planner/) | Decides if a commute is possible based on distance, weather and transport | `if`/`elif`/`else`, booleans, logical operators |
| [Kitchen Inventory Tracker](kitchen-inventory-tracker/) | Tracks ingredients and updates stock as they're used | Functions, `return` vs `print`, local vs global variables |
| [Movie Ticket Booking Calculator](movie-ticket-booking-calculator/) | Checks booking rules and calculates the ticket price | Nested conditionals, `and`/`or`, comparison operators |
| [Bill Splitter](bill-splitter/) | Adds a tip to a restaurant bill and splits it between friends | Variables, arithmetic operators, `+=` |
| [Employee Profile Generator](employee-profile-generator/) | Builds an employee profile and decodes an employee code | String concatenation, f-strings, slicing |
| [Employee Profile Validator](employee-profile-validator/) | Cleans and checks employee names, emails, phone numbers and codes | String methods: `strip`, `find`, `replace`, `split`, `join`, `count` |
| [Report Card Printer](report-card-printer/) | Stores a student's details and checks their data types | Data types, `type()`, `isinstance()` |

## Requirements
Python 3.8 or newer. No external libraries.
