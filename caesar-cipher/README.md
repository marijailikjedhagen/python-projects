# Caesar Cipher

Encrypts and decrypts text by shifting each letter a fixed number of places in the alphabet.
Upper- and lowercase letters are both handled; spaces and punctuation are left unchanged.

```python
encrypt('freeCodeCamp', 3)                          # 'iuhhFrghFdps'
decrypt('Pbhentr vf sbhaq va hayvxryl cynprf.', 13)  # 'Courage is found in unlikely places.'
```

Run it: `python caesar_cipher.py`
